PRAVIDLO: First-Write-Wins
Kdo prvni ulozi do DB, ten ma slot. Druhy dostane notifikaci.
✓
Klient A vyhraje
(write: 18:31:42.103)
Booking → PENDING
❌
Operatorka prohrava
(write: 18:31:42.287)
"Slot prave obsazen"
Technicke reseni: Optimistic locking — kazdy slot ma version counter. UPDATE ... WHERE slot_id = X AND version = Y. Pokud rows_affected = 0 → slot uz nekdo zabral → rollback + notifikace.
